Exercícios Acadêmicos de PHP — Politec

Este projeto reúne um conjunto de 7 exercícios práticos de programação em PHP desenvolvidos durante as aulas do curso Técnico em Informática na Politec.

As atividades têm caráter essencialmente pedagógico e acadêmico, tendo como foco a assimilação de sintaxe, estruturas de controle de fluxo, operadores condicionais, laços de repetição e implementação de regras de negócio fundamentais.

Atividade Escolar:

Estes exercícios pertencem à grade de atividades escolares da escola técnica Politec. Outros exercícios e projetos do ambiente acadêmico permanecem na pasta da escola, enquanto o portfólio pessoal e projetos autônomos são desenvolvidos separadamente em casa.

Conteúdo Real dos 7 Exercícios Desenvolvidos

ex_1.php — Média de Notas e Decisão if/else 
<?php

    $aluno = "McLovin ";
    
    $nota_1 = 0;
    $nota_2 = 10;

    $media = ($nota_1 + $nota_2) / 2;

    if ($media >= 6) {
        $situação = "Aprovado ";
    } else {
        $situação = "Reprovado ";
    }

    echo "Aluno: " . $aluno;
    echo "media: " . $media;
    echo "O aluno está " . $situação;

?>

Enunciado: Receber nome do aluno e duas notas, calcular a média aritmética e verificar se média >= 6 para definir aprovação.

ex_2.php — Laço for e Verificação Par 
<?php

    $num1 = 10;
    $num2 = 30;

    if ($num1 > $num2) {
        $temp = $num1;
        $num1 = $num2;
        $num2 = $temp;
    }

    for ($i = $num1; $i <= $num2; $i++) {
        if ($i % 2 == 0) {
            echo $i . " ";
        }
    }
?>

Enunciado: Receber dois valores e exibir todos os números pares existentes entre eles, ajustando a ordem se necessário.

ex_3.php — Estrutura switch/case para Meses 
<?php
    $numero = 5; 

    switch ($numero) {
        case 1:
            echo "Janeiro";
            break;
        case 2:
            echo "Fevereiro";
            break;
        case 3:
            echo "Março";
            break;
        case 4:
            echo "Abril";
            break;
        case 5:
            echo "Maio";
            break;
        case 6:
            echo "Junho";
            break;
        case 7:
            echo "Julho";
            break;
        case 8:
            echo "Agosto";
            break;
        case 9:
            echo "Setembro";
            break;
        case 10:
            echo "Outubro";
            break;
        case 11:
            echo "Novembro";
            break;
        case 12:

Enunciado: Receber um número de 1 a 12 e imprimir o mês correspondente, tratando valores fora do intervalo.

ex_4.php — Condição de Existência e Classificação de Triângulos 
<?php

    $lado_A = 5;
    $lado_B = 5;
    $lado_C = 5;

    if (
        $lado_A + $lado_B > $lado_C &&
        $lado_A + $lado_C > $lado_B &&
        $lado_B + $lado_C > $lado_A
    ) {

        if ($lado_A == $lado_B && $lado_A == $lado_C) {
            echo "Triângulo Equilátero";
        } elseif ($lado_A == $lado_B || $lado_A == $lado_C || $lado_B == $lado_C) {
            echo "Triângulo Isósceles";
        } else {
            echo "Triângulo Escaleno";
        }

    } else {
        echo "Os valores informados não formam um triângulo.";
    }

?>

Enunciado: Avaliar 3 lados de um triângulo, validar a desigualdade triangular e classificar em Equilátero, Isósceles ou Escaleno.

ex_5.php — Sistema de Empréstimo de Livros 
<?php

    $livro = "E o vento levou";
    $usuario = "Professor"; 

    if ($usuario == "Professor") {
        echo "Professor: Você tem 10 dias para devolver o livro $livro.";
    } elseif ($usuario == "Aluno") {
        echo "Aluno: Você tem 5 dias para devolver o livro $livro.";
    } else {
        echo "Tipo de usuário inválido.";
    }

?>

Enunciado: Sistema de recibo de biblioteca que aplica regra diferenciada de devolução: 10 dias para professores e 5 dias para alunos.

ex_6.php — Tabuada com Laço for 
<?php

$numero = 5; 

echo $numero . ": ";

for ($i = 1; $i <= 10; $i++) {
    echo ($numero * $i) . " ";
}

?>

Enunciado: Gerar e exibir a tabuada de 1 a 10 para o número especificado.

ex_7.php — Autenticação de Usuário e Senha 
<?php

    $usuario = "ADMIN";
    $senha = "123";

    if ($usuario == "ADMIN" && $senha == "123") {
        echo "Acesso OK!";
    } else {
        echo "Acesso Negado!";
    }

?>

Enunciado: Validação de credenciais de acesso por meio de operadores lógicos relacionais.
